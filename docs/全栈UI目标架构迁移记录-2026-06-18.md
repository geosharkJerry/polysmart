# Polysmart 全栈 UI 目标架构迁移记录

## 本轮目标

按照 `www.polysmart.io` 当前品牌方向，把后台与控制台逐步迁移到统一的 React/Next.js + Tailwind 技术栈，并引入以下生产级组件层：

- Refine：后台资源、权限与管理骨架。
- Tremor：KPI 与运营指标卡片。
- ECharts：T+0 价差、置信度、盘口走势等实时可视化。
- Grafana：外部生产监控与告警入口，通过环境变量链接真实 dashboard。
- LangGraph：Oracle agent 的事件、AI、Kelly、执行门禁编排。
- AionUi / Onyx：会员侧 AI 助手工作台的可替换交互入口。

## 已落地文件

- `components/polysmart-ui/RefineRuntimeProvider.tsx`：Refine provider 与后台资源声明。
- `components/polysmart-ui/PolysmartPanel.tsx`：Tailwind 原生面板基础组件。
- `components/polysmart-ui/PolysmartStatusPill.tsx`：Tailwind 状态标签。
- `components/admin/modern/AdminRefineShell.tsx`：新的后台侧栏骨架。
- `components/admin/modern/AdminCommandCenter.tsx`：Tremor KPI、ECharts 价差图、Grafana/LangGraph/AionUi 集成状态。
- `components/admin/modern/SpreadEChart.tsx`：ECharts 价差与 AI 置信度图。
- `lib/services/oracle/langgraph-oracle.ts`：LangGraph Oracle loop 适配器。

## 迁移策略

当前后台原组件仍包含大量 Chakra 表单和表格。为避免破坏已有结算、订阅、账号绑定、执行、审计功能，本轮采取渐进迁移：

1. 新后台首页先挂载 Refine Shell 与 Tailwind command center。
2. 旧详细操作区保留在首页下方，作为迁移期间的功能兜底。
3. 后续逐区把用户表、账号矩阵、支付设置、执行审计表迁移到 Tailwind + Refine resource 页面。
4. 迁移完成后再移除 Chakra provider、旧 `chakra-styles.ts` 与对应组件。

## 生产配置说明

- Grafana dashboard 地址使用 `NEXT_PUBLIC_GRAFANA_DASHBOARD_URL`，未配置时后台显示为 external url missing。
- LangGraph 当前为本地编排适配器，后续可接入自动套利 orchestrator 的事件流。
- AionUi / Onyx 当前作为交互层适配入口，避免和现有 Next.js/Tailwind 技术栈割裂。
