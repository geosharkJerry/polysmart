## 本轮前端优化

- `/workspace` 增加生产访问顺序提示：注册、邮箱验证、付款/托管开通、账号绑定、控制台操作。
- `/console` 增加生产就绪状态条：会话、账号数量、风控状态。
- `/console` Stripe Checkout 回跳地址改为当前访问域名自动生成，支持本地、预览和生产环境。
- `/console` 对关键按钮增加未加载/无会话时的禁用态。
- `/console` 和 `/admin` 补充空数据提示，避免真实环境新库无数据时看起来像页面损坏。
- `/admin` 增加生产接入状态条：AI Secret、Stripe Secret、链上监听 Secret、D1/门禁状态。
- 全局卡片、表格、按钮、空状态样式进一步统一到现有首页风格。

## 本轮 D1 持久化升级

- 账号绑定：`/api/accounts` 和 `/api/accounts/[accountId]` 已切换为 D1 优先读写。
- 账号凭证：绑定账号时同步写入 `account_credentials`，无 D1 时保留运行态回退。
- 钱包充值：`/api/accounts/[accountId]/funding` 和 `/api/onchain/sync` 已切换为 D1 优先同步。
- 钱包充值记录：检测到真实链上转账后写入 `wallet_funding`，并更新账号余额、查询权限、交易权限和同步时间。
- 支付会话：Checkout 创建写入 `payment_sessions`；确认付款更新会话状态、写入 `invoices` 并更新 `billing_profiles` 积分余额。
- 托管佣金：创建与后台结算均支持 `commission_settlements` D1 写入和更新。
- 面板聚合：`/console` 和 `/admin` 工作区 API 已改为 D1 优先聚合账号、充值、支付会话和佣金记录。
